# AMD Ryzen AI 9 H 365 + Radeon 880M（Windows x64）

* **平台**：Windows 11 x64，AMD Ryzen AI 9 H 365（Zen 5，AVX-512），32 GB RAM，AMD Radeon 880M（RDNA 3.5 核显，Vulkan），.NET 10.0.15
* **测试口径**：`test/Sdcb.SimdPaddleOCR.Tests`（`--benchmark --workers 4 --count 100 --warmup 1`），`dataset/` 100 张（共 1036 行），同机 2 轮 ABBA 交替（`v2.0.0 → main → main → v2.0.0`），中位延时取两轮中位的均值
* **对比版本**：`v2.0.0` (`6972083`) vs `main` (`76f210c`)，均为 self-contained `win-x64` 发布
* **测试日期**：2026-11-28

## 小结

* **Zen 5 AVX-512 CPU**：`small` 提速 **23%**，`tiny` +4%，`medium` +5%；输出与 AVX2 / ARM64 NEON / WASM 逐行一致。
* **Radeon 880M Vulkan**：`medium` 提速 7%；`tiny` / `small` 仍比 `v2.0.0` 慢 6% / 3%（与上一版报告的 0.96× / 0.92× 同向，两轮结果一致，非噪声）。相对本机 CPU 加速 **1.9× (`tiny`) / 3.4× (`small`) / 6.5× (`medium`)**。
* **内存**：加载后工作集全档低于 `v2.0.0`；Vulkan 峰值略降（`medium` 1444 → 1416 MB），CPU 峰值高 6–29 MB。
* **精度**：差异来源见 [`5800x-rtx3080ti.md`](5800x-rtx3080ti.md#小结)（解码器 + `small` / `medium` 默认 `UnclipRatio` 1.6）。
