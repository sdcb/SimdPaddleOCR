# Rockchip RK3399（Orange Pi 4 LTS，Linux ARM64）

* **平台**：Orange Pi 4 LTS，Rockchip RK3399（2× Cortex-A72 + 4× Cortex-A53，ARMv8 NEON），4 GB RAM，Ubuntu 22.04 `linux-arm64`，.NET 10.0.15
* **测试口径**：`test/Sdcb.SimdPaddleOCR.Tests`（`--benchmark --engine sharp --workers 4 --warmup 1`），`tiny` 100 张（1036 行）、`small` 25 张（268 行）、`medium` 6 张（63 行），同机 2 轮 ABBA 交替（`v2.0.0 → main → main → v2.0.0`），中位延时取两轮中位的均值
* **对比版本**：`v2.0.0` (`6972083`) vs `main` (`76f210c`)，均为 self-contained `linux-arm64` 发布
* **测试日期**：2026-11-28

## 小结

* 边缘端 ARM64：`tiny` 提速 **11%**（约 1 秒/张），`small` 提速 **38%**，`medium` 持平。
* **内存**：4 GB 小内存板子上，加载后工作集全档低于 `v2.0.0`（`medium` 392 → 356 MB），`medium` 峰值 810 → 796 MB。
* `tiny` 100 张输出（753 / 1036，CER 2.62%）与 x64 AVX2 / AVX-512 / SSE4.2 / WASM **逐行完全一致**。
