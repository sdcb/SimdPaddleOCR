# AMD Ryzen 9 5950X + Intel Arc B580（Windows x64）

* **平台**：Windows Server 2025 x64（`10.0.26100`），AMD Ryzen 9 5950X（16C32T，AVX2），128 GB RAM，Intel Arc B580（Battlemage，Vulkan sg16 协作矩阵），.NET 10.0.15
* **测试口径**：`test/Sdcb.SimdPaddleOCR.Tests`（`--benchmark --workers 4 --count 100 --warmup 1`），`dataset/` 100 张（共 1036 行），同机 **4 轮** ABBA 交替（`v2.0.0 → main → main → v2.0.0` ×2），中位延时取各轮中位的均值
* **对比版本**：`v2.0.0` (`6972083`) vs `main` (`76f210c`)，均为 self-contained `win-x64` 发布
* **环境备注**：该机 24×7 运行 Hyper-V 虚拟机、MinIO 与 `llama-server`，前 2 轮受后台负载干扰（`main tiny CPU` 78.7 / 75.8 ms），后 2 轮安静（59.2 / 59.1 ms，`v2.0.0` 64.0 / 64.8 ms）。下表为 4 轮均值，未剔除。
* **测试日期**：2026-11-28

## 小结

* **CPU**：`small` 提速 **42%**（213.9 → 151.0 ms），`medium` +12%；`tiny` 4 轮均值持平（安静的后 2 轮 `main` 快 8%）。
* **Arc B580 Vulkan**：`medium` **51.3 ms（18.8 img/s，+10%）**，比本机 16 核 CPU 快 **9.4×**；`tiny` / `small` 与 `v2.0.0` 持平（0.97× / 0.99×，在轮间波动范围内）。
* **内存**：加载后工作集全档低于 `v2.0.0`；Vulkan 峰值全档下降（`medium` 937 → **862 MB**）；CPU 峰值高 15–40 MB。
* **精度**：`v2.0.0 → main` 的差异来自测试壳解码器（ImageSharp → `Sdcb.SimdCodecs`）与 `small` / `medium` 默认 `UnclipRatio` 1.4 → 1.6，详见 [`5800x-rtx3080ti.md`](5800x-rtx3080ti.md#小结)。输出与 5800X 逐行一致。
