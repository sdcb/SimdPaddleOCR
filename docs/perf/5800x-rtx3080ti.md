# AMD Ryzen 7 5800X + NVIDIA RTX 3080 Ti（Windows x64）

* **平台**：Windows 11 x64，AMD Ryzen 7 5800X（8C16T，AVX2），128 GB RAM，NVIDIA GeForce RTX 3080 Ti（Vulkan），.NET 10.0.15
* **测试口径**：`test/Sdcb.SimdPaddleOCR.Tests`（`--benchmark --workers 4 --count 100 --warmup 1`），`dataset/` 100 张多尺寸合成图（共 1036 行），同机 2 轮 ABBA 交替（`v2.0.0 → main → main → v2.0.0`），中位延时取两轮中位的均值
* **对比版本**：`v2.0.0` (`6972083`) vs `main` (`76f210c`)，均为 self-contained `win-x64` 发布
* **测试日期**：2026-11-28

## 小结

* **CPU / Vulkan 全档快于 `v2.0.0`**：CPU `small` **1.28×**、`tiny` 1.09×、`medium` 1.07×；RTX 3080 Ti `tiny` **16.3 ms（57.4 img/s）**、`small` **30.5 ms**、`medium` **42.0 ms（比本机 CPU 快 11.9×）**。
* **内存**：加载后工作集全档低于 `v2.0.0`（CPU `medium` 699 → 652 MB）；Vulkan 峰值全档下降（`medium` 1000 → **915 MB**）；CPU 峰值高 10–30 MB。
* **精度**：两个版本的差异有两个来源。
  1. 测试壳解码器：`v2.0.0` 用 `SixLabors.ImageSharp`，`main` 用 `Sdcb.SimdCodecs`（与 libjpeg-turbo 逐像素一致）。4:2:0 色度上采样不同，`tiny` 742 → 753、`small` 950 → 934 的变化即来自这里。
  2. `main` 中 `small` / `medium` 检测框的默认 `UnclipRatio` 由 1.4 改为 **1.6**（`tiny` 保持 1.4）。同一像素上 `small` 934 → **954**（CER 0.68% → 0.58%），`medium` 998 → **1014**（CER 0.38% → 0.31%），同时识别输入变窄、延时下降 2–5%。
  * 因此 `medium` 的 CER 相对 `v2.0.0` 的 0.26% 略高，是解码器差异；同解码器下 1.6 降低了 CER。
* 同机 WebAssembly 基准另见 [`docs/perf/wasm-5800x.md`](wasm-5800x.md)。

## 复现

```powershell
# 两个版本各自 self-contained 发布，然后交替运行
dotnet publish test/Sdcb.SimdPaddleOCR.Tests -c Release -r win-x64 --self-contained -o ab/main
# （在 v2.0.0 的 worktree 中同样发布到 ab/v200）
ab/main/Sdcb.SimdPaddleOCR.Tests.exe --benchmark --benchmark-kind simd --engine sharp  --workers 4 --model tiny --input dataset --count 100 --warmup 1 --out main-tiny-sharp-r1.json
ab/main/Sdcb.SimdPaddleOCR.Tests.exe --benchmark --benchmark-kind simd --engine vulkan --workers 4 --model tiny --input dataset --count 100 --warmup 1 --out main-tiny-vulkan-r1.json
```
